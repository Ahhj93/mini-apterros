# Mini-Apterros
> [!Note]
> Fusée expérimentale du projet Perseus du CNES

Ce dépôt rassemble la conception et la documentation de la mini-fusée Apterros.
L'objectif est de centraliser les ressources techniques pour faciliter le travail de l'équipe.

## Arborescence principale
- `docs/` : documents de référence du projet (présentations, notices, procédures LabVIEW et MATLAB).
- `src/` : ressources techniques et développement (hardware, code Jetson Nano et éléments associés).
- `src/hardware/` : fichiers de conception PCB (versions actuelles et anciennes).
- `src/jetson-nano/` : backend, site web et tests liés à la partie embarquée Jetson Nano.
- `references_composants.md` : référence des composants utilisés dans le projet.
- `CONTRIBUTING.md` : guide de contribution pour participer au dépôt.
